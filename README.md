# Musan

API access management for applications, with webhooks and MCP in the proposed first phase, designed for integration across languages and frameworks.

The project is currently in requirements and research. No implementation has been started.

- [Product requirements draft](docs/PRD.md)
- [Delivery roadmap](ROADMAP.md)
- [Existing software research](docs/research/api-access-landscape.md)
- [Agent instructions](AGENTS.md)

The planned repository is a Turborepo monorepo. Runtime mode, first supported languages, and build-versus-reuse choices remain open for product review.
